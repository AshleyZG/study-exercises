# Python Exercises

Welcome, and thanks for taking part.

## Getting started

1. Open **`problem_a.py`**. Your instructor will tell you when to switch to `problem_b.py`.
2. Work through the exercises in order. Each one is marked `# Exercise 1`, `# Exercise 2`, `# Exercise 3`.
3. Write your code where it says `# your code here`.
4. Run the file whenever you want to check your work:

   ```bash
   python3 problem_a.py
   ```

   Or press the ▶ **Run** button in the top-right of the editor.

## Rules

- **Do not import any modules.** Everything can be done with plain lists, loops, and dictionaries.
- Don't worry if you don't finish every exercise — work at your normal pace.

## Getting help

Open the **AI Feedback** panel from the left sidebar (the speech-bubble icon).

You can type a question there at any time and the AI will answer. Depending on
the session, your instructor may also send you a message through that panel.

Your code is visible to your instructor while you work.
